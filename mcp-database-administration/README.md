# Database Administration with MCP

## Session Overview

This live coding session shows how to use MCP (Model Context Protocol) tools to work with a Postgres database on Supabase.

You will learn how to:
- Connect your editor to Supabase through an MCP server
- Load the Chinook sample dataset
- Ask MCP to inspect tables, relationships, and data
- Use MCP for common database admin tasks like schema inspection and safe updates

By the end of the session, you should be able to:
- Set up a Supabase project for MCP-based database work
- Verify MCP can access your database tools
- Read MCP-generated SQL and understand what it is doing
- Run practical database administration prompts against Chinook

## Prerequisites

- A Supabase account
- VS Code
- Basic familiarity with databases (no SQL expertise required)
